## Synthetic assumptions

- **Heat index** = US NWS approximation (Steadman simple formula; Rothfusz regression when >= 80 F, with low/high-humidity adjustments) from reported temperature and humidity. **Not WBGT**: ignores radiant heat, wind and workload.
- **Temperature** = peak hourly shift temperature; **humidity** = shift mean. Site ambient = site base + seasonal sine (+3.0 C mid-window) + AR(1) daily weather (phi 0.7, sd 1.5 C); night -8.0 C, +15 % RH.
- **Zones**: outdoor = ambient; semi-outdoor +1 C; indoor unconditioned +2 C, -15 % RH; conditioned = setpoint 24 C loosely coupled to ambient; radiant heat +3.0 C. Scenario forcing is damped by zone (conditioned 0.2, indoor unconditioned 0.7, semi-outdoor 0.9, outdoor 1.0).
- **Heat strain** = max(0, true heat index - 32.0 C) x work-intensity factor x exposure hours / 9.5. Outcomes use the *true* environment (sensor noise/faults do not change health).
- **Lags** (weights over current and previous shifts): clinical [0.2, 0.35, 0.25, 0.15, 0.05], absence [0.0, 0.1, 0.2, 0.3, 0.25, 0.15], incidents [0.5, 0.3, 0.2].
- **Rates**: clinic visits ~ Poisson(present x (0.002 + 0.006 x lagged strain)); absence ~ Binomial(rostered, 0.03 + 0.006 x lagged strain, cap 0.4); incidents ~ Poisson(present x (0.0015 + 0.002 x lagged strain)); severity mix shifts toward severe as strain rises.
- **Workforce**: rostered = configured headcount x U(0.9, 1.05); present = rostered - absent; `workforce_data.workforce_count` = present, `absenteeism_data.workforce_count` = rostered. 1 absent shift = 1 lost workday.
- Parameters are illustrative, not calibrated to any real population, and must not be read as epidemiological estimates.

## ML constraints carried into later phases

- Labels and events live only in `data/ground_truth/`; raw sources contain no label columns (tested).
- Use only rows with `reporting_timestamp <= decision time`; rows never reported have no timestamp.
- Baselines/thresholds must be fitted on data before the evaluation window or with time-ordered splits.
- No performance metric is reported until `src/evaluation/` computes it.
